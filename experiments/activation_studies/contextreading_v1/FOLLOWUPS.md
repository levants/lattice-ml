# Adaptive stages and interpretation boundaries

The original operation grid in PROTOCOL.md was fixed after reading the
four source chunks and before the new extent computations. It contains
no dataset-label selection. All 330 group/rule/condition cases remain.

The close-reading stage chose TC11 research, mixed-domain, biological and
Cat/dog cases; SAE11 New/de; and research meets across other blocks.
Small chosen extents were read completely; larger ones used the fixed
first-two-plus-six sample. The replay module records every selected case.
The sample was chosen without a semantic success score, but choosing the
cases themselves is exploratory. These are not new-corpus estimates.

A candidate relation between coordinate 4355 and put/place complements
emerged from the source occurrence and all six mixed-pair joined items.
Seven single-token verb replacements were then fixed, one for each of
those contexts. Original target positions and sequence lengths were kept.
After these replacements produced zero target activation, a second
exploratory control replaced the verbs within the put/place family.
The alternative forms preserve positive activation in all seven cases,
but only one reaches the original query threshold. This counterexample
to amplitude invariance is retained. Every suffix control preserves the
complete target code exactly. These are input contrasts, not internal
latent ablations or downstream causal-pathway validation.

The existing Pythia snippets suggested an early-period/title-boundary
association; SmolLM2 snippets suggested name-fragment activity. For each
fixed historical one-coordinate join, sixteen test members and sixteen
nonmembers were sampled with seed 20261004, without consulting class labels.
The source groups and old outcomes were already known, so the analyst is
not blinded. The text/trace interpretation was recorded before the new
label comparison. Categories are a later descriptive check, not the
criterion used to decide whether these outputs have a relationship.
