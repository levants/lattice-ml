# Contextual activation witnesses

This extension replays saved GPT-2 full-amplitude meet queries and tests
prefix-order sensitivity at their maximal token witnesses. It does not
train models or turn contextual illustrations into semantic labels.

- Code: `src/lattmc/contextstudy/` (no underscore in the package name).
- Notebook: `notebooks/sae/contextual_witnesses_codexgen.ipynb`.
- Protocol: `experiments/activation_studies/context_v1/PROTOCOL.md`.
- Canonical arrays and token records: `data/activation_studies/context_v1`.
- Tables: generated by `report_codexgen.py` into the paper's `tables/`.

Run from the repository root with its existing uv environment:

```sh
PYTHONPATH=src uv run --locked python -m lattmc.contextstudy.run_codexgen
PYTHONPATH=src uv run --locked python -m lattmc.contextstudy.audit_codexgen
PYTHONPATH=src uv run --locked python -m lattmc.contextstudy.report_codexgen
```

Inference needs the historical GPT-2 models, token cache, and six saved
query archives in their documented canonical locations. It runs offline;
missing inputs cause an error. The report command defaults to the paper
checkout; in the code-only repository pass `--paper /path/to/paper`.

The notebook executes the independent cached-array audit and displays all
48 cases. Neural inference was executed separately by the source module,
not by its display cells. The three main-paper examples were selected
for exposition from the complete seeded sample; neither the sample nor
the gallery measures semantic precision. Exact token IDs and unrounded
activations remain in the data records. Whole-word exclusion does not
exclude subword overlap, as the `catheter` counterexample demonstrates.

All 48 replayed rows satisfy the original full query. Of 144 prefix
permutations, 119 change token order; all 119 materially change the chosen
activation, and 95 cross below its threshold. All 48 suffix controls are
exactly unchanged. These are dependent descriptive outcomes. A lost
witness is not necessarily a lost row, since max pooling may find another
witness elsewhere. Prefix shuffling can also destroy grammaticality.

The local release candidate contains the four small array/JSON result
pairs, audit, protocol, source code, and executed notebook. It excludes
the full corpus cache and upstream weights. No artifact has been uploaded.
Local mirrors may use relative cache links; a fresh clone must restore the
input artifacts separately. Maintained package names now omit underscores. Frozen protocols and
archives preserve their original historical paths; see the migration
manifest for the old-to-new mapping.
